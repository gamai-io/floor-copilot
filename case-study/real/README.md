# Real invoice OCR pilot (private)

The pilot was executed locally on GAMA's own/available invoices.

- Source files and per-invoice results are kept **private** in `/root/gama_private_invoices` (0700).
- No customer names, filenames, invoice numbers or amounts are published.
- Aggregate metrics are withheld from this public repository by owner request.
- `run_real_invoices.py` is the methodology/reproducer; it does not contain data.

The synthetic case studies in `case-study/` and `case-study/realistic/` remain public and contain no customer data.
