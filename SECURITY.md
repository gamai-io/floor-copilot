# Security policy

Report vulnerabilities to **security@gamai.io**. Please do not open public issues for unresolved findings.

## Scope
- Invoice intake, OCR parsing and the 17% VAT arithmetic gate in this repository.
- Not in scope: the upstream OCR engine, or deployments outside this repository.

## What we ask for
- Steps to reproduce, including a minimal synthetic invoice (no real customer data).
- Impact assessment and, if possible, a suggested fix.

## Notes
- Case-study data in this repository is synthetic. Names, prices and identifiers are illustrative and are not a commercial offer.
- No secrets are stored in the repository; configuration comes from the environment.
